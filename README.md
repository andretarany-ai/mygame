# Моя игра — школьная викторина

Викторина для 4 игроков (Марина, Даша, Андрей, Сережа). Каждый играет со своего телефона.

## Правила
- **3 раунда** по 6 тем × 5 вопросов (100–500, 200–1000, 300–1500) + **финал**.
- Выбирающий игрок открывает вопрос. Пока вопрос читается, кнопка заблокирована;
  потом загорается красная кнопка **«ЖМИ!»** — кто нажал первым, тот отвечает (25 секунд).
- Ответ **вписывается с большой буквы и без ошибок**. Маленькая первая буква = неверно.
  (Регистр остальных букв, «ё/е», точка в конце не важны.)
- Верно: **+стоимость** и право выбирать следующий вопрос. Неверно: **−стоимость**,
  и остальные могут нажать кнопку снова.
- В каждом раунде спрятан **«Кот в мешке» 🐱** — выбравший отдаёт его сопернику, тот обязан ответить.
- Со 2-го раунда первым выбирает игрок с наименьшим счётом.
- **Финал**: играют только игроки с положительным счётом. Ставка от 1 до всего счёта, затем
  все одновременно пишут ответ (45 с).

Меню «⋯»: сменить игрока, пропустить остаток раунда, прервать игру.
Режим «Только смотреть» — табло для телевизора/ноутбука.

## Запуск дома (все в одном Wi‑Fi)
Нужен Node.js 18+.
```bash
npm install
npm start
```
В консоли появится адрес вида `http://192.168.1.5:3000` — откройте его на всех телефонах.

## Хостинг в интернете (можно играть из разных мест)
Бесплатно через [Render](https://render.com): New → Blueprint → выберите этот репозиторий
(файл `render.yaml` уже настроен). Получите ссылку `https://moya-igra-xxxx.onrender.com`
и отправьте её всем игрокам. (На бесплатном тарифе сервер «засыпает» — первое открытие ~30 с.)

## Вопросы
Все вопросы в `questions.js`: `q` — вопрос, `a` — ответ, `alt` — другие принимаемые варианты.
