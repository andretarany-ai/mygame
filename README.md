# Моя игра — викторина для взрослых

Викторина для 4 игроков (Марина, Даша, Андрей, Сережа). Каждый играет со своего телефона.
Темы: история и география Украины, бренды и машины по картинкам, приложения, игры, косметика,
бьюти-услуги, музыка, кухня, Америка, коктейли, отношения, 18+ и другие.

## Правила
- **3 раунда** по 6 тем × 5 вопросов (100–500, 200–1000, 300–1500) + **финал**.
- Выбирающий игрок открывает вопрос. Пока вопрос читается, кнопка заблокирована;
  потом загорается красная кнопка **«ЖМИ!»** — кто нажал первым, тот отвечает (25 секунд).
- Ответ **вписывается**. Большие и маленькие буквы не важны, мелкие опечатки прощаются,
  засчитывается часть ответа («Кит» = «Синий кит»). Проверка — в `answer-check.js`.
- **Андрей** может менять баллы всем игрокам: меню «⋯» → «Изменить баллы».
- Верно: **+стоимость** и право выбирать следующий вопрос. Неверно: **−стоимость**,
  и остальные могут нажать кнопку снова.
- В каждом раунде спрятан **«Кот в мешке» 🐱** — выбравший отдаёт его сопернику, тот обязан ответить.
- Со 2-го раунда первым выбирает игрок с наименьшим счётом.
- **Финал**: играют только игроки с положительным счётом. Ставка от 1 до всего счёта, затем
  все одновременно пишут ответ (45 с).

Меню «⋯»: сменить игрока, пропустить остаток раунда, прервать игру.
Режим «Только смотреть» — табло для телевизора/ноутбука.

## Запуск дома (все в одном Wi‑Fi)
Нужен Node.js 18+.
```bash
npm install
npm start
```
В консоли появится адрес вида `http://192.168.1.5:3000` — откройте его на всех телефонах.

## Хостинг в интернете (можно играть из разных мест)
Бесплатно через [Render](https://render.com): New → Blueprint → выберите этот репозиторий
(файл `render.yaml` уже настроен). Получите ссылку `https://moya-igra-xxxx.onrender.com`
и отправьте её всем игрокам. (На бесплатном тарифе сервер «засыпает» — первое открытие ~30 с.)

## Вопросы
Все вопросы в `questions.js`: `q` — вопрос, `a` — ответ, `alt` — другие принимаемые варианты.

## Версия без сервера (только телефон)
Вся игра в одном файле. Собирается командой `node standalone/build.js` из `standalone/template.html`,
`standalone/mqtt-room.js` и `questions.js`:
- `docs/index.html` — сайт для **GitHub Pages**. Вход по ссылке без регистрации: хост создаёт игру,
  отправляет ссылку, каждого вошедшего разрешает кнопкой. Телефоны связываются через публичный
  MQTT-брокер (public.cloud.shiftr.io на порту 443, запасные — broker.emqx.io и broker.hivemq.com).
- `standalone/moya-igra.html` — та же игра для страницы claude.ai (там онлайн только для вошедших в аккаунт).

### Как включить GitHub Pages (можно с телефона, в браузере на github.com)
1. Settings → General → Danger Zone → **Change visibility → Public** (бесплатные Pages работают только для публичных репозиториев).
2. Settings → **Pages** → Source: *Deploy from a branch* → ветка `claude/admiring-goodall-1cv0sh`, папка **/docs** → Save.
3. Через 1–2 минуты игра откроется по адресу `https://andretarany-ai.github.io/mygame/`.

## Иббенбюрен: наша команда (настольная игра про бизнес)
Адрес: `https://andretarany-ai.github.io/mygame/ibbenburen/` (кнопка есть и в меню викторины).
- `ibbenburen/engine.js` — поле, карточки и все правила (покупка, аукцион, аренда, дома и отели,
  залог, сделки, тюрьма, долги и банкротство). Кубики — криптографически честный случай у хоста.
- `ibbenburen/template.html` — интерфейс и 3D-поле на Three.js (камера за спиной фишки во время хода).
- Сборка: `node ibbenburen/build.js` → `docs/ibbenburen/index.html`.
